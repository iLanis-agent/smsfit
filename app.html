SmsFit

Paste your text message. See which encoding it needs, how many segments it costs, and which character is doing the damage.

What it costs

Encodings: GSM-7 (the 3GPP TS 23.038 default alphabet, read from the table on the Wikipedia GSM 03.38 page) holds 160 characters in one message and 153 per segment in a longer one. Anything outside that alphabet switches the whole message to UCS-2 (UTF-16), which holds 70 in one message and 67 per segment. Both limits match Twilio's SMS character limit table. Characters from the GSM extension table ( ^ { } \ [ ~ ] | and the euro sign) cost two septets. The tool does not let a two-unit character straddle two segments (an extension pair, or an emoji), which is how I understand handlers to behave; I could not confirm this from a primary source, so a carrier or provider may count one segment differently. The "smart punctuation" fix replaces curly quotes, en and em dashes, the ellipsis and the non-breaking space with plain ASCII. National language shift tables, delivery reports, link shorteners and provider-added opt-out text are not modelled. The default price is only an example: use your provider's rate. Runs in your browser, nothing stored.
